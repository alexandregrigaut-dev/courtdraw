Build a Coaching Play Library You Never Redraw

Most coaches redraw the same handful of plays every season because nothing from last year survived — the whiteboard got wiped, the phone photo got lost. A named, organized library fixes that permanently. Here's how to set one up.

Why Coaches Keep Rebuilding the Same Plays

A physical whiteboard has no memory — it gets wiped for the next session and whatever was on it is gone. A phone photo library has no structure — after a season it's a scroll of unlabeled screenshots with no way to find "that zone press variation from October." The result is the same play redrawn from scratch every year, or worse, forgotten entirely.

A digital library only pays off if it's actually organized. Saving plays with no naming system just moves the mess from a whiteboard to an app.

A Naming System That Scales

Use a consistent prefix so plays sort and search cleanly as the library grows:

  • Group or level first — "U14," "Varsity," "Adult Beginner" — so you can filter to what's relevant for today's session.
  • Play name second — "Cross-Court Rally," "Zone Press," "Inbound Play A."
  • Result: "U14 — Cross-Court Rally." Scanning a list of thirty saved plays this way is instant; scanning thirty plays named "Play 1," "Play 2," "New Tactic" is not.

Organizing by Purpose, Not Just Sport

If you coach one sport across multiple groups, or multiple sports entirely, group plays by their role in a session — warm-up patterns, technical drills, competitive-game setups, match-day tactics — rather than one flat list. This mirrors how you'll actually reach for them: you rarely need "every play I've ever saved," you need "today's warm-up options" or "our zone defense variations."

Keeping It Current Season to Season

At the start of each season, don't rebuild — open last year's library, archive or delete anything that's no longer relevant, and duplicate-and-tweak what still applies for the new group. A play that worked for last year's U12s might need simpler cone spacing for this year's group; adjusting a saved play takes thirty seconds, drawing it from scratch doesn't.

Sharing the Library Beyond Yourself

A library only you can see helps only you. If you work with assistant coaches, export key plays as PNG for the team chat, or — on the Club plan — give the whole coaching staff access to one shared library so a play built by one coach is immediately usable by everyone else. See the guide on running one shared library across a multi-sport club for how that works day to day.

FAQ

Play Libraries — Questions

What naming convention should I use for saved plays?

A consistent prefix works best: group or level, then play name — e.g. "U14 — Cross-Court Rally." That keeps the library sortable as it grows.

How many saved tactics can I keep on the free plan?

Three. That's enough for a single session but not a real library — most coaches building a season's worth of plays upgrade to Pro for unlimited saves.

Can multiple coaches at the same club share one library?

Yes, on the Club plan. Up to 10 coaches draw from and contribute to one shared library.
